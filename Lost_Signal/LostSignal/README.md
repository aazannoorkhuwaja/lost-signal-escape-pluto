# Lost Signal — Escape Pluto
Open project.godot in Godot 4 and press F6 with Pluto.tscn open, or F5. Landscape mobile controls support simultaneous movement and jump. Keyboard: arrows move, Space jumps or replays, Tab scans.
Recover three components across the crash site, ice ridge and crater. The scanner points briefly toward the nearest remaining part, then toward your ship. Falls and rock impacts return you to the most recent pickup with progress intact.
Theme: Lost. The astronaut investigating a missing signal must use a scanner to find scattered parts and navigate home.
Team: add registered team name and members before submission.
Assets: procedural graphics, engine default font. AI assistance: ChatGPT implemented the GDScript prototype and procedural visuals and checked mission state transitions from the team's concept.
Android: install matching Godot Android export templates and configure the Android SDK and Java in editor settings. Add an Android preset under Project > Export and export a debug APK for device testing.
